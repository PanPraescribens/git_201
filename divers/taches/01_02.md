# Cours 1 - Exercice 2 — `.gitignore`

1. `td go 2` — le repo de l'exercice 1 est copié automatiquement, vous y êtes
2. Créez un `.gitignore` qui ignore le dossier `secrets/` et le fichier `A_FAIRE.md`
3. Créez `secrets/secrets.txt` → `git status` ne doit RIEN montrer
4. `A_FAIRE.md` refuse de disparaître de `git status` ? Il est **déjà suivi** :
   le `.gitignore` seul ne suffit pas → `git rm --cached A_FAIRE.md`
5. Commit + `git tag ex02`
