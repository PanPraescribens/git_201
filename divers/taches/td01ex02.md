# td01ex02 — ce que vous devez faire

1. Copiez le repo de l'exercice 1 : `cp -R ../td01ex01 .` (ou dupliquez-le ici)
2. Modifiez `main.txt`, `git add .`, commit — oups, secrets.txt est parti avec !
3. `git rm secrets.txt` + `git commit --amend` — et là, il a complètement disparu
4. `git reset --hard HEAD~1` — l'erreur disparaît… et vos modifs dans main.txt aussi !
5. Retrouvez tout ça avec `git reflog` + `git checkout <hash> -- main.txt`
6. Protégez-vous : créez un `.gitignore` qui ignore `secrets/`… et rappelez-vous
   `A_FAIRE.md` ! (indice : `.gitignore` ne suffit pas, il est déjà suivi)
7. Commit final + `git tag ex02`

➡️ Le détail de chaque étape : `pratiques/td_01/td_01.md` dans le clone du cours.
