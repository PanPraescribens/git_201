# Cours 1 - Exercice 4 — l'index n'est pas votre éditeur

1. Nouveau repo : `cd ..`, `mkdir 01_04`, `cd 01_04`, `git init` (ou `td go 4`)
2. Créez `poeme.txt` avec 2 lignes, puis `git add poeme.txt`
3. Ajoutez une 3e ligne SANS re-stager (`echo ... >> poeme.txt`)
4. `git status` : le fichier est à la fois « staged » et « modified » — quoi ?!
5. `git diff` vs `git diff --cached` : les deux versions coexistent
6. Commit, puis comparez `cat poeme.txt` et `git show HEAD:poeme.txt`
   — laquelle des deux versions a été commitée ?
7. Réparez avec `git add` + `git commit --amend`, vérifiez, `git tag ex04`
