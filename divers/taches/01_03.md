# Cours 1 - Exercice 3 — amend, reset --hard et reflog

1. Copiez le repo de l'exercice 2 : `cd ..`, `cp -R 01_02/. 01_03`, `cd 01_03`
2. Modifiez `main.txt` ET créez `config_local.txt` (avec un mot de passe dedans…)
3. `git add .` + commit — oups : `config_local.txt` n'était PAS ignoré !
4. `git rm config_local.txt` + `git commit --amend` — corrigé, mais le fichier
   a complètement disparu du disque (et il n'est pas ignoré !)
5. `git reset --hard HEAD~1` — l'erreur disparaît… et vos modifs dans
   `main.txt` aussi !
6. Retrouvez tout : `git reflog` + `git checkout <hash> -- main.txt`
7. Réparation durable : ajoutez `config_local.txt` au `.gitignore`,
   commit + `git tag ex03`
