# Cours 1 - Exercice 5 (bonus) — soft / mixed / hard

1. Nouveau repo : `cd ..`, `mkdir 01_05`, `cd 01_05`, `git init` (ou `td go 5`)
2. Faites 3 commits rapides (`echo ligne >> compteur.txt` + `git add compteur.txt`
   + `git commit`)
3. `git reset --soft HEAD~1` → observez `git status` : tout est re-stagé,
   le fichier est intact
4. Re-commitez, puis `git reset HEAD~1` (mixed, le défaut) → modifs présentes
   mais non stagées
5. Re-commitez, puis `git reset --hard HEAD~1` → tout disparaît !
6. Sauvetage : `git reflog` + `git reset --hard <hash>` pour revenir au présent
7. `git tag ex05` — moralité : soft garde tout, mixed garde le disque,
   hard ne garde rien
