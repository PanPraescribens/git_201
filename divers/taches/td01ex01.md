# td01ex01 — ce que vous devez faire

1. `git init` dans ce dossier
2. Créez `main.txt` (vide) et `secrets.txt` avec du texte dedans
3. `git add .` — tout passe à l'index… trop !
4. Retirez `secrets.txt` de l'index avec `git rm --cached`
5. `git commit -m "Ajoute main.txt"`
6. Recommencez le retrait avec `git restore --staged` puis `git reset HEAD`
   (maintenant que HEAD existe, ils fonctionnent !)

➡️ Le détail de chaque étape : `pratiques/td_01/td_01.md` dans le clone du cours.
